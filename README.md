# 📱 Umar Farooq Mobile Zone - Shop Management System (Next.js)

A complete, full-stack POS & Shop Management application built with **Next.js (App Router)**, **React 19**, **Mongoose / In-Memory Store**, and **Lucide Icons**.

---

## ✨ Key Features

- **🚀 Point of Sale (POS)**: Fast barcode/IMEI scanning, cart management, instant receipt generation, thermal/A4 printing, and direct WhatsApp invoice dispatch.
- **📦 Inventory & Stock Management**: Real-time stock levels, dual IMEI tracking, cost/sale pricing, minimum stock alerts, and audit logs.
- **📒 Customer Khata / Ledgers**: Track credit customers, payment histories, running balances, and issue payment receipts.
- **🚚 Supplier Ledgers**: Supplier purchase orders, debt/credit ledgers, payouts, and purchase returns.
- **💰 Financial Reports & P&L**: Profit & Loss calculations, gross vs. net profits, inventory valuations, daily/monthly summaries.
- **🧾 Expense Tracking**: Category-wise store expenses (rent, electricity, salaries, bills) with analytics.
- **🎨 Modern Design System**: Cyber Dark, Clean Light, and Ocean Teal themes with glassmorphism UI.
- **🔒 Role-Based Security**: Admin and Staff accounts with granular permissions.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router)
- **Frontend**: React 19, Vanilla CSS Design System, Lucide React
- **Backend APIs**: Next.js Serverless Route Handlers (`app/api/...`)
- **Database**: MongoDB with automatic in-memory fallback store
- **Authentication**: JWT & Bcrypt

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
